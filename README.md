# Doc's Lab

**LIVE STAGING:** [Azure Static Web Apps](https://kind-bush-04a42f20f.6.azurestaticapps.net)

Doc's Lab is Kenneth J. Smith's documentation-first laboratory for exploring how a coherent semantic model can support multiple representations: a direct, accessible site; diagnostic views; and future interactive or spatial experiences. This public mirror contains a small, reviewable slice of that work.

## Reviewer path

1. [Open the live Azure staging site](https://kind-bush-04a42f20f.6.azurestaticapps.net).
2. Review the portfolio, diagnostics, and logs there.
3. Read the [architecture](docs/architecture/), [evidence](docs/evidence/), and [devlog](docs/devlog/) records here.

## Current status

The semantic-site is an isolated prototype. It demonstrates a direct, responsive presentation of structured content and is not a claim of production readiness, accessibility certification, client delivery, or measured performance. Azure staging is live on an Azure-generated HTTPS hostname; production DNS, custom domains, and GitHub deployment integration remain separate decisions.

The design principle is simple: one semantic source can drive several representations while each representation preserves truthful status and accessible fallback paths. Assembly is a future composition layer for Unreal-oriented work; it does not replace the direct web experience or make the Unreal projects in the canonical workspace public.

## What is included

- The approved semantic-site prototype source and its dependency manifests.
- Selected architecture and product records.
- Sanitized deployment and prototype evidence.
- A lightweight public publication policy and milestone devlog.

Vendor/Fab/Marketplace packages, Unreal binaries and maps, Diagnostic Fox media/source, generated state, credentials, account metadata, and private coordination records are deliberately excluded. Their omission protects provenance, redistribution, privacy, and reproducibility boundaries.

This is **not** the canonical full development workspace. The canonical local workspace remains private and broader. Azure staging operates independently of GitHub; this mirror is documentation and source publication, not an Azure control plane or deployment dependency.
