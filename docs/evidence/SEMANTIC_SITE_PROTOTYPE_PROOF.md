# Semantic-site Prototype Proof

Status: prototype evidence, not production launch evidence.

The isolated semantic-site prototype has been checked for its documented local workflow: dependency resolution, TypeScript typechecking, production build, direct route behavior, shared portfolio presentation, and narrow viewport layout. The prototype intentionally avoids a required WebGL path, production integrations, analytics, contact backends, client claims, employment claims, and measured performance claims.

The source lives at [`prototypes/semantic-site/`](../../prototypes/semantic-site/). Re-run the package scripts from that directory to reproduce the checks.

Limitations: this record does not certify accessibility, browser coverage, production readiness, or performance. Those require separately scoped validation.
