# Responsive strategy

Desktop uses a two-column hero and 2–3 column work grid. Laptop reduces art and density. Tablet becomes one reading column with a compact work grid. Phone uses a single column, horizontal filter scrolling only when labeled, and no canvas by default. Narrow phones prioritize copy, CTA, and evidence captions over decorative media.

At every size: preserve readable line length, 44px controls, stable image aspect ratios, no layout shift from media, and no required hover. At 200% zoom the page remains usable; at 400% zoom content may become one column but must not be clipped.
